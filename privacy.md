# Privacy Policy

Last updated: November 2026

NanoClaw Personal Assistant ("the app") is a private, self-hosted tool used only by its owner and the owner's family members who choose to connect their own Google accounts.

## Data accessed

With the user's explicit consent, the app accesses the connected user's Gmail messages and labels and Google Calendar events, only to perform tasks the user requests (for example summarizing email, applying labels, or managing calendar events).

## Use and storage

Data is processed on a server controlled by the owner. OAuth tokens are stored encrypted. Data is not sold, shared with third parties for advertising, or used for any purpose other than providing the assistant's features to the user who connected the account.

## Google API Services

The app's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Users can revoke the app's access at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
